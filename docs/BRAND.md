## 1. Signature：Slack 訊息就是產品的門面

判決書是使用者會**截圖轉發**的東西。它必須看起來像一份公文：

**有案號、有被告、有罪名、有證據、有判決、有量刑。**

用 Block Kit 的 `divider` 與 ` ``` ` 等寬區塊做出公文感，**不是一坨 emoji**。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  刑事判決書                      案號 #1042
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  被告   @alice · commit a3f9c1
  案由   acme/web · CI · build-web
  罪名   未經測試即部署

  ── 證據 ──────────────────────────────
  ```
  CI job `build-web` 於第 3 步崩潰
  TypeError: cannot read property 'map' of undefined
    at parseUsers (src/api/client.ts:42)
  ```

  ── 根因假設 ────────────────  信心：中
  API 回傳型別變更後未同步更新 client 端型別定義。

  ── 建議修法 ──────────────────────────
  於 src/api/client.ts:42 補上 null 檢查並更新型別定義。

  ── 量刑 ──────────────────────────────
  輕罪。建議自行修復。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 [ 查看 CI ]  [ 👍 有用 ]  [ 👎 沒用 ]
 Build Failure Prosecutor · 分享此卡片
```

### 版面鐵則

- 每則訊息最多 **2 個 emoji**（回饋按鈕上的 👍👎 不計）。
- 標題列、分隔線、標籤欄位固定，讓它「每次都長一樣」——公文的力量來自格式的一致。
- 證據區永遠是等寬區塊。它是「證物」，不是聊天內容。
- 信心程度顯示在根因假設**同一行的右側**，不能藏起來。
- 底部固定帶產品連結與分享連結（免費且持續的曝光）。

## 2. Voice：法庭書記官的冷靜 + 一絲刻薄

**用詞正式，內容毒。**

### 永遠禁止（所有強度皆適用）

| 禁止 | 為什麼 |
|---|---|
| 對人不對事 | R5。指控的對象永遠是**行為**，不是**人的能力** |
| 針對能力的評價（「連這都不會」「太粗心」） | 同上 |
| 提及非工作時間的行為（「你凌晨三點還在推 code」） | R5。深夜提交常常是被迫的 |
| emoji 濫用 | 破壞公文感 |
| 「哈哈」「笑死」「XD」 | 這是判決書不是群組閒聊 |
| 自我調侃的 AI 語氣（「身為一個 AI 法官…」「我只是個機器人啦」） | 廉價、破壞角色、每個 bot 都這樣 |
| 驚嘆號連發 | 書記官不會激動 |
| 對根因的過度自信措辭（「顯然是」「一定是」） | 見 R-03。用「假設」「推定」 |

### 永遠必須

- 根因假設與建議修法**具體到可行動**：檔案、行號、要改什麼。
- 推不出來就寫「本案證據不足，待補」，並說明缺什麼證據（如「log 未包含堆疊資訊」）。
- 「非戰之罪」的失敗（`E_INFRA` / `E_TIMEOUT` / `E_NETWORK` / `E_OOM`）要**主動說明不是人的問題**。

## 3. 毒舌強度 0–3

同一個案件（TypeError，未更新型別定義）在四個強度下的**罪名 + 量刑**：

### Level 0 — 完全正經（企業預設）

無戲劇化用語。連「被告」「罪名」都換成中性詞。

```
建置失敗通知                          #1042

  提交    a3f9c1 · alice
  範圍    acme/web · CI · build-web
  類型    型別錯誤

  現象    build-web 第 3 步失敗
          TypeError: cannot read property 'map' of undefined
          at parseUsers (src/api/client.ts:42)

  根因假設（中信心）
          API 回傳型別變更後未同步更新 client 端型別定義。

  建議    於 src/api/client.ts:42 補上 null 檢查並更新型別定義。

  影響    低。不影響已部署版本。
```

> Level 0 仍然保留「根因假設 / 信心 / 建議」的結構。**戲劇化可以關掉，triage 不行。**

### Level 1 — 預設

書記官的冷靜。用詞正式，一絲刻薄，但不加碼。

> **罪名**：未經測試即部署
> **量刑**：輕罪，建議自行修復。

### Level 2 — 加一點戲

允許法庭修辭與輕度誇飾，仍然對事不對人。

> **罪名**：對 `undefined` 抱持不當信任
> **量刑**：輕罪。念在初犯，本庭從輕發落，惟限期修復。

### Level 3 — 最毒

修辭密度拉滿，**但紅線一條都不能碰**：不人身攻擊、不評價能力、不提非工作時間。

> **罪名**：明知型別已變更，仍執意相信 API 會善待你
> **量刑**：輕罪，惟情節可議。本庭建議被告於修復前，先與 `strictNullChecks` 和解。

**Level 3 的自我檢查**：把這句話裡的人名換成你自己，你還笑得出來嗎？笑不出來就是越線了。

## 4. 中英文

- `locale: zh-TW` 為主要語言，`en` 為次要。
- 英文版**不是翻譯，是改寫**——法庭修辭的笑點無法直譯。英文版走 `In the matter of ...` / `The defendant stands accused of ...` 的英美法庭語彙。
- 技術名詞（TypeError、strictNullChecks、CI job 名）永遠保留原文，不翻譯。

## 5. 視覺規範

### 色彩

法庭感：**深色調 + 一個克制的暖色（黃銅）**。

| 角色 | 用途 |
|---|---|
| `ink` | 最深的底色。近黑但帶一點藍或棕，**不是純黑** |
| `panel` | 比 `ink` 稍亮的面板／區塊底 |
| `brass` | 唯一的暖色重點。標題色塊、法槌、金屬細節、CTA |
| `paper` | 文件／紙張的淺色，用得節制 |
| `muted` | 次要文字與線條 |
| `alert` | 僅用於 `critical` 量刑的極少量點綴 |

實際色碼於 Phase 3 由 `illustrator` 提案、Tech Lead 定稿後回填此表。

### 明確要避開的「AI 樣板長相」

| ✗ 禁止 | 為什麼 |
|---|---|
| 米白底 + 大襯線標題 + 陶土橘 | 現在每個 AI 產品都長這樣 |
| 純黑 + 螢光綠 | 「駭客風」已經是自嘲了 |
| 大數字 + 漸層 accent 的 hero | 樣板 |
| 三欄 feature 卡片 + 圖示 | 樣板 |
| 漸層陰影堆疊、玻璃擬態 | 與扁平向量的場景風格衝突 |

### 迷因卡場景風格

延續**法庭母題**，每個場景是一個獨立的小場景插畫：被告席、證物袋、法槌、卷宗塔、深夜辦公室剪影……

| 規範 | 內容 |
|---|---|
| 風格 | 扁平向量。線條俐落，不用漸層、不用陰影堆疊 |
| 色階 | 有限色階，沿用上表的角色色（深色 + 黃銅） |
| 母題 | 從**法庭語彙**出發（證物、法槌、卷宗、傳票、鐵閘），而不是從「表達某情緒的人」出發 |
| 人物 | 盡量用剪影或極簡化造型，避免可辨識的個人特徵 |
| 文字 | 等寬字體，置於畫面上方或下方的**實心色塊**內，**永不壓在插畫細節上** |
| 版面 | 1200×630。標題色塊高度隨行數（最多 2 行）變動 |
| 浮水印 | 角落固定帶專案名 + repo 連結 |

**判準（產品負責人原話）**：
> 這是原創插畫，不是「哏圖模板配字」——**場景本身要好看到值得單獨欣賞**，標題只是最後一擊。

### R7 原創性紅線

`illustrator` **不得**參照任何既有梗圖的構圖、人物配置、姿勢或標誌性元素。
Distracted Boyfriend、Drake、Two Buttons、Woman Yelling at Cat 等全部是受版權保護素材，重現、局部拼接、「重畫成向量版」皆不可。

「從法庭語彙出發」這個約束本身就是最好的防抄襲設計——法庭沒有對應的知名梗圖構圖。

每個場景的設計發想來源記錄於 `docs/MEME_SCENES.md`，作為原創性稽核軌跡。

## 6. 第一則訊息（Onboarding）

安裝後的第一則判決書要有 onboarding 意味，且**必須**包含：

1. 這是什麼、為什麼你會收到
2. 「原始 log 不落地」的一句話隱私聲明
3. 怎麼調毒舌強度、怎麼開匿名、**怎麼 opt-out**（R5：opt-out 是個人權利，要主動告知）
4. 怎麼靜音／解除安裝（誠實地告訴他們怎麼關掉，是取得信任最便宜的方法）
