## 原創性聲明（R7）

**本專案的所有迷因場景皆為原創插畫。**

我們**不使用**任何真實迷因梗圖模板。Distracted Boyfriend、Drake、Two Buttons、
Woman Yelling at Cat、Surprised Pikachu 等廣為流傳的梗圖，全部是受版權保護的
攝影作品、漫畫或影視截圖。「大家都在用」不構成授權。重現、局部拼接、
或「重畫成向量版」同樣不可。

**防抄襲的設計方法**：所有場景一律從**法庭語彙**出發（證物袋、法槌、卷宗、
傳票、鐵閘、被告席），而不是從「表達某種情緒的人」出發。後者是梗圖的母語，
極容易在無意識中滑向既有構圖；前者沒有對應的知名梗圖，因此這個約束本身
就是最有效的防護。

每個場景在下方記錄**設計發想來源**，作為原創性的稽核軌跡。
Tech Lead 對每個交付的場景額外做一次「這像不像我看過的東西」人工檢查。

**授權**：本場景庫的 SVG 原始碼與衍生 PNG 由本專案原創並持有著作權，
授權方式於 Phase 5 隨專案 LICENSE 決定。內嵌字型使用 SIL OFL 授權字型
（Noto Sans TC / 思源黑體），可商業使用。

## 視覺規範

見 `docs/BRAND.md` §5。摘要：扁平向量、有限色階（深色 `ink` + 黃銅 `brass`）、
線條俐落、不用漸層陰影堆疊、人物用剪影或極簡造型、文字置於實心色塊內
永不壓在插畫細節上。

**判準**：場景本身要好看到值得單獨欣賞，標題只是最後一擊。

## 場景清單（10 個）

> 狀態：`spec`（僅規格）→ `draft`（SVG 已交付）→ `accepted`（視覺驗收通過）

### `SC01_FIRST_SUMMONS` — 初犯傳票

| 欄位 | 內容 |
|---|---|
| **畫面** | 空蕩的法庭，一張傳票正飄落在空的被告席上 |
| **情緒** | 事情剛開始。不嚴重，但已經進入程序 |
| **主要觸發** | 首次出現的失敗；以及所有規則都沒命中的 catch-all |
| **規則優先序** | `999`（catch-all，永遠命中） |
| **設計發想** | 從「傳票送達」這個司法程序的起點出發。空的被告席暗示「還沒有人被定罪」，符合 blameless 立場 |
| **狀態** | `spec` |

### `SC02_REPEAT_OFFENDER` — 累犯卷宗

| 欄位 | 內容 |
|---|---|
| **畫面** | 疊得過高的卷宗塔，最上層貼著案號標籤，塔身微微傾斜 |
| **情緒** | 又來了。累積感、疲憊感，但不指向任何人 |
| **主要觸發** | 同 error signature 在 7 天內重複出現 |
| **規則優先序** | `70`（repeat_tier == 2）、`110`（repeat_tier == 1） |
| **設計發想** | 從「案卷歸檔」出發。**關鍵設計約束**：卷宗上的標籤是**案號**，不是人名——累犯的計數單位是 error signature，不是人（D-10 / R5） |
| **狀態** | `spec` |

### `SC03_MIDNIGHT_BENCH` — 深夜長凳

| 欄位 | 內容 |
|---|---|
| **畫面** | 空法庭、窗外一輪月亮、桌上一盞小燈與一杯已經冷掉的咖啡 |
| **情緒** | **陪伴，不是嘲笑。** 「還有人在」 |
| **主要觸發** | 深夜時段的失敗 |
| **規則優先序** | `90`（`is_late_night && config.meme.late_night_scene`） |
| **預設** | **關閉**（`meme.late_night_scene: false`） |
| **設計發想** | 從「夜間值班的法庭」出發。⚠️ **本場景與 R5「不得提及非工作時間行為」存在張力**，因此預設關閉、調性定為同情而非指控、且標題禁止提及時間。深夜提交常常是被迫的（線上事故、時區差異），拿它開玩笑會精準傷到最辛苦的那個人。最終處置待產品負責人拍板（`RISKS.md` Q3） |
| **狀態** | `spec` · **pending Q3** |

### `SC04_MISSING_EVIDENCE` — 空證物袋

| 欄位 | 內容 |
|---|---|
| **畫面** | 一個透明證物袋，標籤上寫著「測試」，袋子是空的 |
| **情緒** | 缺了該有的東西 |
| **主要觸發** | 測試失敗，且本次提交沒有變更任何測試檔 |
| **規則優先序** | `80` |
| **設計發想** | 從「證物袋」這個法庭物件出發。空袋子是對「沒有測試」最直接的視覺隱喻，且完全不涉及人 |
| **狀態** | `spec` |

### `SC05_DEPENDENCY_HELL` — 纏繞的卷宗

| 欄位 | 內容 |
|---|---|
| **畫面** | 辦案板上用紅線纏成一團的檔案與圖釘，線已經纏到看不出關聯 |
| **情緒** | 一團亂，理不清 |
| **主要觸發** | 依賴解析／安裝失敗（`E_DEPENDENCY`） |

| **狀態** | `spec` |

### `SC06_ONE_LINE_VERDICT` — 一行判決

| 欄位 | 內容 |
|---|---|
| **畫面** | 法槌落在一張只寫著一行字的判決書上 |
| **情緒** | 乾淨俐落。這是**正面**的場景——問題很小，去改吧 |
| **主要觸發** | 建議修法明確且範圍極小（有檔案 + 行號）且量刑為 minor |

| **設計發想** | 從「簡易判決」出發。這是場景庫裡少數帶有鼓勵意味的一張，刻意保留——不是每次都要挖苦 |

| 欄位 | 內容 |

| **情緒** | 嚴重。這次不是小事 |
| **主要觸發** | 量刑 critical；或 deploy workflow 且量刑 serious |
| **規則優先序** | `30`、`50` |
| **設計發想** | 從「宣判」的力度出發。裂痕是唯一允許使用 `alert` 色的地方 |

### `SC09_COURT_CLOSED` — 閉庭

| 欄位 | 內容 |
|---|---|
| **畫面** | 拉下的鐵閘、熄燈的法庭，牆上一張「非戰之罪」的告示 |
| **情緒** | 不是你的錯。系統壞了 |
| **主要觸發** | `E_INFRA` / `E_TIMEOUT` / `E_NETWORK` / `E_OOM` |
| **規則優先序** | `20` |
| **設計發想** | 從「法院今天不開門」出發。**這個場景是 R5 的具體落實**：當失敗不是人造成的，畫面就不該指控任何人。它的存在本身是產品立場的宣示 |
| **狀態** | `spec` |

### `SC10_INSUFFICIENT` — 證據不足

| 欄位 | 內容 |
|---|---|
| **畫面** | 一支放大鏡照著一張空白的紙 |
| **情緒** | 我們不知道。誠實地不知道 |
| **主要觸發** | `confidence == "insufficient"` |
| **規則優先序** | `10`（最高優先） |
| **設計發想** | 從「證據調查」出發。這是整個產品最重要的一張卡——**它讓「我不知道」變成一個有設計、有尊嚴的輸出，而不是失敗狀態**。核心洞察說推不出根因就誠實說證據不足，這張卡是那句話的視覺化 |
| **狀態** | `spec` |

## 場景選擇規則

完整決策表見 `SPEC.md` §8.3。要點：

- **輸入特徵全部確定性**，不含任何未經伺服器夾制的 LLM 自由文字。
- 規則存於 `scenes/rules.json`，first-match-wins，最後一條必為無條件 catch-all。
- **程式碼不含任何場景 ID 字面量**（D-04 / 預留項 c）——加場景不需改程式碼。
- 測試以特徵空間的笛卡兒積窮舉，驗證每組恰好命中一個場景（Gate P3）。

## 標題規範

| 項目 | 規範 |
|---|---|
| 長度 | ≤ **24 display units**（CJK/全形 = 2、ASCII = 1）≈ 12 中文字 |
| 內容 | 只能濃縮公訴詞 JSON 中已有的事實。**禁止引入新事實或新指控**（R7） |
| 禁止 | 人名、@ mention、URL、emoji、標點結尾 |
| 截斷 | 重問 LLM → 標點/CJK 邊界切 → grapheme 邊界硬切 + `…` → 模板標題 |
| 驗證 | 標題中的識別符 token 必須全部出現在輸入 JSON 或錯誤區段中 |
